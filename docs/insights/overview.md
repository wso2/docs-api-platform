Insights shows how your APIs are used. Its dashboards turn API traffic into trends, so you can see how traffic is distributed, where failures occur, which consumers are most active, and how usage changes over time.

## Dashboards

| Dashboard | Use It To |
|:----------|:----------|
| [Overview](../monitoring-and-analytics.md#overview) | Get a quick view of platform health across API traffic, LLM requests, MCP tool calls, and consumer activity. |
| [APIs](../monitoring-and-analytics.md#apis) | Analyze traffic, errors, and performance by API type, such as REST, GraphQL, and gRPC. |
| [LLM APIs](../monitoring-and-analytics.md#llm-apis-analytics) | Track provider and model usage, token consumption, estimated cost, latency, guardrail activity, and semantic cache performance. |
| [MCP](../monitoring-and-analytics.md#mcp-analytics) | Track tool call volume, consumer sessions, error rates, and traffic across MCP servers and clients. |

You can filter every dashboard by environment and time range.

To troubleshoot issues with logs, alerts, and gateway metrics, see [Observability](../observability/overview.md).
