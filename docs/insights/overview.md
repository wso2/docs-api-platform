Insights is powered by Moesif Basic, which is included with your WSO2 subscription. WSO2 gateways send telemetry to Moesif, so you can monitor traffic, review how the platform is used, and diagnose latency without setting up a separate analytics pipeline.

## Analytics Dashboards

The **Overview** dashboard summarizes usage for your APIs, LLM proxies, and MCP servers in the selected time period. Open a specific dashboard to filter by API, LLM proxy, or MCP server.

### Analytics Overview

- Unique users, total requests, and total errors
- LLM traffic and MCP traffic
- Overall platform metrics and the consumer onboarding trend
- Top applications and top APIs
- Traffic breakdown across APIs, LLM proxies, and MCP
- Traffic intensity by hour, top platforms and user agents, average latency over time, and geographic heatmaps

### API Analytics

- Total requests, average latency, error rate, and unique consumers
- Traffic for REST, Async, GraphQL, gRPC, and SOAP APIs
- Latency and traffic volume over time, errors over time, and error types
- Traffic intensity by hour, top platforms and user agents, and geographic heatmaps

### LLM Analytics

- Unique consumers, total requests, average error rate, token usage, and estimated cost
- AI application details, cost trend by LLM provider, and traffic share by provider and model
- Request intensity by hour, latency trend, and AI API details
- Guardrail trigger statistics and error types

### MCP Analytics

- Tool calls, unique consumers, error rate, and unique sessions
- Top tools by calls, client distribution, and unique consumers over time
- Server traffic distribution and MCP application details
- Error rate trend, error types, tool call execution errors, and traffic volume over time
