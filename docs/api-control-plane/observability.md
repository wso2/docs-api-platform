From the API Control Plane, you can investigate failed API calls and review the changes that users make in your organization.

| Task | Description |
|:-----|:------------|
| [Troubleshoot API calls](../observability-and-insights/runtime-logs.md) | Search the gateway access logs of your API proxies, and filter them by environment and log level. |
| [Review user actions](../observability-and-insights/audit-logs.md) | View audit logs of operations that users perform in the API Platform Console, such as creating, updating, and deleting API proxies. |

For all the observability features of API Platform Cloud, see [Observability](../observability/overview.md).
