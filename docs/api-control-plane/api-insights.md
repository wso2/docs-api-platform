---
title: "API Insights"
description: "View how an API is used, such as its traffic, errors, and performance."
---

API Insights shows how your APIs are used, directly from the console. You can monitor API traffic and overall platform health. Its dashboards turn raw API traffic into trends and operational insight, so you can see how traffic is distributed, where failures occur, which consumers are most active, and how usage changes over time.

To open API Insights, select the project and the API in the header, and in the left navigation menu, click **Insights**, then click **API Insights**.
