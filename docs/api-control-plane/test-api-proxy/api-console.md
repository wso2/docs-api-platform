---
title: "API Console"
description: "Test a deployed REST API from the Console view in the API Platform Console."
---

API Platform provides an integrated OpenAPI Console that lets you test REST endpoints for API proxies after deploying them to a gateway.

Follow these steps to test a REST endpoint using the OpenAPI Console:

1. Sign in to the [API Platform Console](https://console.bijira.dev).
2. Select the project and API proxy you want to test.
3. In the left navigation menu, click **Test**, then select **Console** to open the **OpenAPI Console** pane.
4. Select the target environment from the environment drop-down list.
5. Expand the resource containing the endpoint you want to test.
6. Click **Try it out** to enable testing.
7. Enter values for the required parameters, if applicable.
8. Click **Execute** to invoke the endpoint. The response appears in the **Responses** section.
