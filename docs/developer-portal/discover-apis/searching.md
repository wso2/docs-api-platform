---
title: "Searching"
description: "Search published APIs in the API Portal and AI Hub by name, type, version, or description."
---

You can search for APIs in the API Portal that have already been published from API Platform Cloud.

1. Click **APIs** from the sidebar.APIs list can be seen

    ![Developer Portal APIs list showing multiple API cards with name, version, type, and Subscribe button](/img/cloud/devportal/apis-list.png)

2. Use one of the following methods to search:

    | **Category**     | **Explanation**                          |
    |------------------|------------------------------------------|
    | **Name**         | Full or partial name of the API          |
    | **Type**         | Type of the API (e.g., REST)             |
    | **Version**      | Version of the API (e.g., v3.5)          |
    | **Description**  | Full or partial description of the API   |

    Example: Searching by API version.

![Search bar with v4.5 query returning Reading List API REST card as the matching result](/img/cloud/devportal/api-search.png)
