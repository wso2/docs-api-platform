API Platform Cloud gives you visibility into how your APIs and gateways behave, so you can spot problems early and troubleshoot them.

## What You Can Do

| Task | Description |
|:-----|:------------|
| Logs | Troubleshoot API proxies with [runtime logs](../observability-and-insights/runtime-logs.md), and review user actions in your organization with [audit logs](../observability-and-insights/audit-logs.md). |
| [Alerts](../monitoring-and-analytics/alerts.md) | Get notified when your APIs or gateways need attention. |
| [Gateway Metrics](../monitoring-and-analytics/gateway-metrics.md) | Track the health and resource usage of your gateways. |

To analyze API traffic, errors, and consumer activity over time, see [Insights](../insights/overview.md).
