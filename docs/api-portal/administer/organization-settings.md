title: "Organization settings"
description: "Edit the organization name, business owner, and control plane reference from Settings in the API Portal and AI Hub."
---

**Organization** in **Settings** is where you edit the organization you are signed in to.

1. Sign in to the API Portal and AI Hub as an admin.
2. Open **Settings**.
3. Under **ORGANIZATION**, select **Organization**.

## Fields

| Field | Description |
|---|---|
| **Name** | Required. The display name of the organization. |
| **Handle** | The identifier used in portal URLs. It cannot be changed. |
| **Name**, **Contact**, **Email** | The business owner. These fields are under **BUSINESS OWNER**. |
| **IDP reference ID** | Read-only. The identity provider reference for this organization. |
| **Control plane reference ID** | The reference included for this organization. It is under **REFERENCES**. |

Click **Save changes**.

This page edits the current organization. It does not create or delete organizations.
