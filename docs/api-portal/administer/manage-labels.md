---
title: "Manage labels"
description: "Create labels that group APIs and MCP servers so views can control what is visible."
---

A **label** groups APIs and MCP servers. A [view](./manage-views.md) shows the APIs and MCP servers that carry the labels selected for that view.

1. Sign in to the API Portal and AI Hub as an administrator.
2. Open **Settings**.
3. Under **ORGANIZATION**, select **Labels**.


## Add a label

Click **Add label**.

| Field | Description |
|---|---|
| **Name** | Required. The name shown when you assign the label. |
| **Handle** | Required. The lowercase identifier used internally. It cannot be changed. |

## Edit or delete a label

Click **Edit** to change a label. Click **Delete** to remove it.

Assign labels while you create or edit an API, on **Labels and tags** in [Manage APIs](./manage-apis.md). Select the same labels on a view so the API appears there.
