---
title: "Manage MCP servers"
description: "Add, edit, and remove the MCP servers exposed in the API Portal and AI Hub."
---

**MCP Servers** under **Settings** is where you add, edit, and remove the MCP servers this portal exposes.

1. Sign in to the API Portal and AI Hub as an administrator.
2. Open **Settings**.
3. Under **CONTENT**, select **MCP Servers**.

The list columns are **MCP Server**, **Version**, and **Status**. When the list is empty, the page says to click **Add MCP Server** to get started.

Click **Add MCP Server**. The wizard is titled **Create MCP Server** and uses the same three steps as [Manage APIs](./manage-apis.md): **Details**, **Spec**, and **Assets**.

Select one or more rows and click **Delete selected** to remove them.
