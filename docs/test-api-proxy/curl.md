title: "cURL"
description: "Copy a cURL command for a deployed API from the API Platform Console."
---

Testing is an essential part of API development. API Platform simplifies this process by generating cURL commands that you can use to invoke and test your APIs.

Follow these steps to generate a cURL command and test an API operation:

1. Sign in to the [API Platform Console](https://console.bijira.dev).
2. Select the project and API you want to test.
3. In the left navigation menu, click **Test**, then select **cURL** to open the **cURL** pane.
4. Select the target environment from the environment drop-down list.
5. Select the HTTP method from the **Method** list.
6. Open the **Parameters** tab and add the required parameters.
7. Open the **Headers** tab and configure the required headers.
8. Open the **Body** tab and select the appropriate body type and provide the request body, if required.
9. Copy the generated cURL command.
10. Run the command in a terminal or another cURL-compatible client to invoke and test the API operation.
